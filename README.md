# Shield Insurance Analysis Dashboard

## Overview
This Power BI dashboard analyzes Shield Insurance's business performance across revenue, customers, policies, sales channels, cities, and age groups. It helps stakeholders identify growth opportunities and make data-driven decisions. 【1-b3efda】

## Key Metrics
- Total Revenue: 989M
- Total Customers: 26,841
- Total Policies Sold: 26,841
- Daily Revenue Growth: 5.47M
- Daily Customer Growth: 148.29 【1-b3efda】

## Key Insights
- Offline-Agent generates 55.67% of total revenue.
- Delhi NCR is the highest revenue-generating city.
- Age group 31–40 contributes the highest revenue (284M).
- March 2023 recorded the highest monthly revenue (264M). 【1-b3efda】
